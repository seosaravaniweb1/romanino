# قالب «انتشارات سرو»

قالب اختصاصی وردپرس + ووکامرس برای فروشگاه فایل و کتاب مذهبی (ادعیه، زیارات
و متون معنوی). بر پایهٔ زیرساخت فنی قالب رمانینو ساخته شده و ظاهر آن مطابق
رابط کاربری «سرو» بازطراحی شده است.

---

## نصب

۱. فایل `saro.zip` را از مسیر **پیشخوان → نمایش → پوسته‌ها → افزودن پوسته →
   بارگذاری پوسته** آپلود و فعال کنید.
۲. افزونهٔ **WooCommerce** باید نصب و فعال باشد (قالب بدون آن کار نمی‌کند).
۳. پیشنهادی: افزونهٔ **Rank Math** برای سئو، و یک افزونهٔ تقویم شمسی
   (مثل wp-parsidate) تا تاریخ‌ها خودکار شمسی شوند.

## تنظیمات اولیه (۵ دقیقه)

| کجا | چه کاری |
| --- | --- |
| پیشخوان → **هدر و فوتر انتشارات سرو** | تیتر و تصویر بخش «هرو»، متن جست‌وجو، بخش «مشکل‌گشای شما اینجاست»، لینک‌ها و اطلاعات تماس فوتر، نمادهای اعتماد، قاب پس‌زمینهٔ فوتر، پلن‌های عضویت ویژه، سؤالات متداول و باکس اعتماد صفحهٔ محصول |
| نمایش → **سربرگ سایت** | آپلود لوگو (اگر لوگو نگذارید، نام و توضیح کوتاه سایت نمایش داده می‌شود) |
| نمایش → **فهرست‌ها** | ساخت «منوی اصلی (هدر)»، «فوتر - لینک‌های سایت» و «فوتر - لینک‌های کاربری» |
| تنظیمات → **خواندن** | صفحهٔ اصلی روی «آخرین نوشته‌ها» بماند تا صفحهٔ اصلی سرو نمایش داده شود |
| یک برگه با نامک `about` بسازید | متن و تصویر شاخص آن، بخش «دربارهٔ ما»ی صفحهٔ اصلی را پر می‌کند |

## ثبت محصول

- **ویژگی‌های اثر** (متاباکس پایین صفحهٔ محصول): هر عبارتی که اینجا بنویسید —
  مثل «مناسب جذب انرژی و قدرت» یا «مناسب افزایش ثروت» — دقیقاً به همان شکل و
  **بدون هیچ عنوان یا توضیحی** به‌صورت چیپ در صفحهٔ محصول نمایش داده می‌شود.
- **مشخصات فنی** (قطع، صحافی، زبان و…): از بخش «ویژگی‌ها/Attributes» خودِ
  ووکامرس وارد کنید؛ در تب «مشخصات» صفحهٔ محصول می‌آیند.
- **حجم فایل** و **لینک نمونهٔ رایگان** هم در همان متاباکس هستند: حجم فایل فقط
  در Schema استفاده می‌شود و لینک نمونه، دکمهٔ «دریافت نمونهٔ رایگان» را
  فعال می‌کند.
- محصول را **دانلودی (Downloadable)** و **مجازی (Virtual)** بزنید.

## نکته‌های طراحی که عمداً این‌طور پیاده شده‌اند

- **ترتیب هدر:** اول مگامنوی «دسته‌بندی محصولات»، بعد آیتم‌های منوی «اصلی (هدر)».
- **لوگو:** اسلات لوگو ارتفاع ثابت دارد و تصویر داخلش `position:absolute` است؛
  یعنی لوگوی بزرگ ارتفاع هدر/فوتر را کش نمی‌دهد و به‌جای آن از کادر بیرون
  می‌زند (به سمت پایین، مثل کتیبه). روی دسکتاپ، لوگو داخل یک «کتیبهٔ» سفید از
  هدر آویزان می‌شود و روی تصویر هرو می‌نشیند؛ مقدار آویز از
  **تنظیمات قالب → هدر → «آویز لوگو روی تصویر»** تنظیم می‌شود تا دقیقاً وسط
  گودیِ بین دو شاخ قوسِ تصویر محراب شما بنشیند (چون قوسِ هر تصویری جای
  متفاوتی دارد). فاصلهٔ تیتر هرو خودکار با همین عدد هماهنگ می‌شود.
- **دکمهٔ ورود/پنل کاربری:** فقط یکی از این دو در هر لحظه نمایش داده می‌شود —
  کاربر مهمان «ورود / ثبت‌نام» می‌بیند و کاربر واردشده «پنل کاربری» با حرف اول
  نامش.
- **قاب فوتر:** با `border-image` به شکل «۹ تکه» رسم می‌شود؛ چهار گوشهٔ
  نگاره‌دار هرگز کشیده نمی‌شوند و فقط ضلع‌ها کش می‌آیند — به همین دلیل قاب در
  موبایل و دسکتاپ یکسان و درست دیده می‌شود. قاب پیش‌فرض یک فایل SVG برداری
  است (`assets/img/footer-frame.svg`) و از پیشخوان قابل تعویض است.
- **دسته‌بندی‌های صفحهٔ اصلی:** همیشه اولین دسته از سمت راست، قاب طلاییِ
  متمایز را می‌گیرد.

## ساختار فایل‌ها

```
saro/
├── style.css                 هدر استاندارد پوستهٔ وردپرس
├── functions.php             راه‌اندازی، enqueue، متاباکس محصول، Schema
├── header.php / footer.php   هدر، فوتر، کشوی سبد، مودال ورود
├── index.php                 صفحهٔ اصلی
├── archive-product.php       آرشیو فروشگاه (بدون سایدبار)
├── taxonomy-product_cat.php  صفحهٔ دسته‌بندی (بدون سایدبار)
├── single-product.php        صفحهٔ محصول
├── page-login.php            صفحهٔ مستقل ورود/ثبت‌نام
├── inc/                      توابع سئو، احراز هویت، سبد، چک‌اوت، تنظیمات
├── template-parts/           کارت اثر، کارت نوشته، محتوای محصول، مینی‌کارت
├── woocommerce/              بازنویسی قالب‌های پنل کاربری و چک‌اوت
└── assets/
    ├── css/tailwind-src.css      ← منبع استایل (اینجا را ویرایش کنید)
    ├── css/tailwind-build.css    ← خروجی کامپایل‌شده (این را دستی ویرایش نکنید)
    ├── fonts/                    ایران‌سنس + نسخ عربی (میزبانی محلی)
    ├── img/                      تصویر محراب و قاب‌های هشت‌ضلعی دسته‌بندی
    └── js/                       main.js و mini-cart.js
```

## تغییر استایل

رنگ‌ها فقط در یک جا تعریف شده‌اند: بلوک `:root` در
`assets/css/tailwind-src.css`. بعد از هر تغییر در آن فایل یا افزودن کلاس
Tailwind تازه به تمپلیت‌ها، در ریشهٔ قالب اجرا کنید:

```bash
npm install
npm run build:css
```

> ⚠️ هر رنگ دو شکل دارد: خوانا (`--teal: #114b52`) و کانالی
> (`--teal-rgb: 17 75 82`). اگر رنگی را عوض کردید، **هر دو** را با هم
> به‌روزرسانی کنید؛ وگرنه کلاس‌هایی مثل `bg-teal/40` از کار می‌افتند.

## نکات فنی

- هیچ درخواستی به CDN خارجی (از جمله Google Fonts و Tailwind CDN) زده
  نمی‌شود — همهٔ فونت‌ها و استایل‌ها روی سرور خودتان میزبانی می‌شوند.
- صفحه‌های سبد، تسویه‌حساب و حساب کاربری خودکار `noindex` و بدون کش می‌شوند
  (سازگار با WP Rocket و LiteSpeed).
- ورود با کد پیامکی از سرویس **ippanel** استفاده می‌کند؛ کلید API و کد پترن
  را از تب «پیامک (OTP)» در تنظیمات قالب وارد کنید.
