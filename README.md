# قالب رمانینو (Romanino Minimal)

قالب اختصاصی وردپرس برای فروشگاه رمان و فایل دیجیتال، بر پایه‌ی WooCommerce و Tailwind CSS.

---

## پیش‌نیازها

| مورد | حداقل نسخه | توضیح |
|---|---|---|
| PHP | **8.0** | قالب از Union Type و توابع PHP 8 استفاده می‌کند. روی PHP 7.4 یک Parse Error رخ می‌دهد و سایت بالا نمی‌آید. یک گارد در `functions.php` به‌جای صفحه‌ی سفید، پیام واضح نمایش می‌دهد. |
| وردپرس | 6.0 | |
| WooCommerce | فعال | قالب بدون آن روی صفحات فروشگاه کار نمی‌کند (توابع حیاتی گارد `function_exists` دارند). |
| Node.js | 18+ | فقط برای بیلد CSS در زمان توسعه؛ روی سرور لازم نیست. |

## راه‌اندازی

### ۱. بیلد CSS — **الزامی**

فایل `assets/css/tailwind-build.css` در مخزن نگه‌داری می‌شود، ولی هر بار که
`tailwind-src.css`، `tailwind.config.js` یا کلاس‌های داخل تمپلیت‌ها تغییر
می‌کنند باید دوباره ساخته شود:

```bash
npm install
npm run build:css      # تولید نسخه‌ی minify‌شده
npm run watch:css      # حالت توسعه
```

> بدون این مرحله، حالت روشن (Light Mode)، استایل بخش نقد و بررسی و تایپوگرافی
> محتوا (`.rmn-prose`) هیچ‌کدام دیده نمی‌شوند.

### ۲. پیوندهای یکتا

پس از فعال‌سازی قالب، یک‌بار به **تنظیمات → پیوندهای یکتا** بروید و ذخیره کنید.
این کار قانون بازنویسی `/dl/{id}/` (مسیر دانلود رمان‌های رایگان) را ثبت می‌کند.

### ۳. تنظیمات ووکامرس — **مهم برای امنیت**

**ووکامرس → تنظیمات → محصولات → دانلودها → روش دانلود فایل** را روی
`Force downloads` یا `X-Accel-Redirect/X-Sendfile` بگذارید.

قالب دیگر مسیر خام فایل را در HTML چاپ نمی‌کند، ولی اگر پوشه‌ی آپلود در سطح
سرور باز باشد، هر کسی که مسیر را از قبل دارد همچنان می‌تواند دانلود کند.

### ۴. اگر سایت پشت CDN است

اگر از کلودفلر، ابرآروان یا هر CDN دیگری استفاده می‌کنید، این خط را به
`wp-config.php` اضافه کنید:

```php
define( 'ROMANINO_TRUSTED_PROXY', 'cloudflare' ); // یا 'arvan' یا 'generic'
```

بدون آن، `REMOTE_ADDR` برای همه‌ی بازدیدکنندگان برابر IP خود CDN است و
محدودیت‌های نرخ (rate limit) کل کاربران سایت را با هم بلاک می‌کند.

### ۵. پنل پیامکی (اختیاری — برای ورود با کد یک‌بارمصرف)

```bash
composer require ippanel/php-rest-sdk
```

سپس **پیشخوان → تنظیمات قالب رمانینو → تب پیامک (OTP)** را پر کنید.

## نکات معماری

### رنگ‌ها و حالت روشن/تاریک

تمام رنگ‌ها در `assets/css/tailwind-src.css` به‌صورت CSS Variable تعریف
می‌شوند؛ `html.light` همان متغیرها را با پالت روشن بازتعریف می‌کند.

بخشی از تمپلیت‌های قدیمی‌تر (هدر، فوتر، صفحه اصلی، صفحه محصول) هنوز رنگ ثابت
دارند (`bg-[#0b0514]` و مشابه). یک «لایه‌ی نگاشت» زیر `html.light` آن‌ها را به
متغیرها وصل می‌کند.

> **بدهی فنی شناخته‌شده:** مهاجرت آن تمپلیت‌ها به توکن‌ها
> (`bg-background`, `text-foreground`, `border-border`) این لایه را کاملاً
> حذف می‌کند. تا آن زمان، **هر رنگ ثابت جدیدی که به تمپلیت‌ها اضافه شود باید
> نگاشت متناظرش هم به آن بلوک اضافه شود**، وگرنه در حالت روشن تیره می‌ماند.

### سئو

اگر Rank Math (یا Yoast/SEOPress/AIOSEO) فعال باشد، قالب **هیچ** تگ سئویی چاپ
نمی‌کند — نه canonical، نه Open Graph، نه اسکیما. کنترل این رفتار:

```php
add_filter( 'romanino_seo_plugin_active', '__return_true' );  // خاموش کردن سئوی قالب
```

### کش

بلوک‌های محصول صفحه اصلی و فوتر با Transient کش می‌شوند و با
`save_post_product` باطل می‌گردند. نانس‌ها عمداً داخل HTML چاپ **نمی‌شوند** و
از `/wp-json/romanino/v1/nonce` گرفته می‌شوند تا با کش کامل صفحه سازگار باشند.
